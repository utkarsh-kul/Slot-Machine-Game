# 🎰 Slot Machine Game

A 2D slot machine game developed in Unity.

## 🎮 Features
- 3-reel slot machine
- Multiple symbols
- Reel-based architecture
- Symbol data system
- UI-based gameplay

## 🛠️ Built With
- Unity 6
- C#
- Universal Render Pipeline (2D)

## 📂 Project Structure

Assets/
├── Scenes/
├── Scripts/
│   ├── Core/
│   ├── Data/
│   ├── UI/
│   └── Utilities/
└── Sprites/
