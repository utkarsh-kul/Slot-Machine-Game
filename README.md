# Slot Machine Game

A 2D slot machine game developed in Unity as part of a game development assignment.

## Features

- 3-reel slot machine
- Multiple symbols: 7, Cherry, Bell and BAR
- Randomized reel results
- Credit-based spin system
- Configurable payouts
- Animated lever interaction
- Custom spin button with pressed state
- Paytable UI
- Win / loss result feedback
- Button, lever, reel and win sound effects
- Jackpot reward system
- WebGL build included

## How to Play

1. Start with 100 credits.
2. Click the **SPIN** button to play.
3. Each spin costs 10 credits.
4. Match three symbols to receive a payout.
5. Use the **PayTable** button to view the available rewards.

### Payouts

| Combination | Reward |
|-------------|--------|
| 7 - 7 - 7 | +100 |
| Cherry × 3 | +50 |
| Bell × 3 | +30 |
| BAR × 3 | +20 |

## Built With

- Unity 6
- C#
- Unity UI / TextMeshPro
- Unity 2D
- WebGL

## Project Structure

- `Assets/` — Game assets, scripts, UI, audio and scenes
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings
- `Build/WebGL/` — WebGL build

## WebGL Build

The WebGL build is included in:

`Build/WebGL/`

The build can be hosted on a WebGL-compatible web server to play in a browser.
